How to read the results

Passed: the test did everything a user would and checked both the screen and the saved data. Known defect reproduced: the test checks the correct behaviour and fails exactly where the app is wrong; when the app is fixed, the test reports it. Failed: an unexpected failure, traced to a cause before it is reported. No real user data is touched: external services are simulated inside the tests, except the opt-in live tests, which use a dedicated QA account and remove what they create.
